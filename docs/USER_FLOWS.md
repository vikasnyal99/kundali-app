# User Flows

## First run
Splash -> language chooser (English / हिन्दी) -> concise introduction/privacy notice -> Home. Optional sign-in must not block trial.

## Match two people
Home / New Match -> Choose saved Person 1 or Add Person -> Choose saved Person 2 or Add Person -> Review birth details -> Generate Match -> progress status -> Match Summary -> Detailed Koota/Manglik sections -> AI/traditional interpretation -> Download PDF -> Saved Reports.

## Compare multiple candidates (priority feature)
Home / Compare -> choose a **fixed Person 1** -> choose/add Person 2 candidates (2 or more; configurable max e.g. 20) -> review chosen names -> Compare -> sortable ranking table/cards with 36-point totals and warnings -> tap candidate for side-by-side breakdown -> change **only Person 2** selection without resetting Person 1 -> add/remove candidates -> recompare -> optionally change fixed Person 1 explicitly. Cached scores invalidated when birth input/engine settings change.

## Profiles
People -> list/search -> add/edit/delete -> explicit confirm before delete. An individual can be reused in several comparisons.

## Reports
Reports -> recent matches, dates, processing badge -> view details -> download/share signed file -> retry failed reports. Do not expose bucket name or public URLs as permanence guarantees.

## Errors
Missing birth time/timezone -> clear message; AI unavailable -> deterministic explanation; calculation fails -> retry with error code; report pending -> show status; signed link expired -> request fresh link.
